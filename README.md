# Original Source Training Club

The landing page for Original Source Training Club, served at https://originalsource.co.

One static page: `index.html`, plus icons (`favicon-32.png`, `apple-touch-icon.png`, `icon-512.png`) and the link-preview image (`og-image.png`). No build step.

- **Hosting:** GitHub Pages, from the `main` branch. `CNAME` sets the custom domain.
- **Visitor stats:** GoatCounter (`ostrainingclub.goatcounter.com`).
- **Join buttons:** the Stripe Payment Link for OS Training Club. After payment, Stripe sends people to `/welcome` (`welcome.html`).
